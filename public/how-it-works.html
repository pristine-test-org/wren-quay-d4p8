How Wren Quay works

Wren Quay keeps one shared list and shows the newest items on the landing page, so everyone sees the same thing.

  1. Add an item to the shared list from any device.
  2. Check it off when it is done; finished items show a tick.
  3. Watch the five newest items appear on the landing page.

Every visitor reads the same list, which is fetched fresh each time the landing page loads, so nothing on screen is ever out of date.
